# Development Roadmap

✅ 20 bot instances
✅ Guild join requests
✅ Auto-accept requests
✅ Team formation

## Known Limitations

- Simulates Free Fire API (not actual game integration)
- In-memory storage (resets on restart)
- Single guild per instance
- Basic bot AI
